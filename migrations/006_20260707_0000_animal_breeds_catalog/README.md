# animal_breeds_catalog

`animal_breeds` solo tenía un registro placeholder ('VACA'), que no es una raza. Se reemplaza
por un catálogo real de razas comunes en la ganadería boliviana (Nelore, Brahman, Senepol,
Sindi, Holstein, Pardo Suizo, Jersey, Criollo Boliviano, Mestizo), agrupadas por función
(carne/leche/criollas). El id=1 se renombra en vez de borrarse para no romper animales que ya
lo tengan asignado.
